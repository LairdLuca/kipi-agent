=== STEP 1 — INSTALL NODE.JS AUTOMATICALLY ===

First check: node --version
If you get v18 or higher → say "✓ Node ready" and go to Step 2.

If missing or too old, install it YOURSELF. Try these methods in order; STOP at the first one that succeeds.

--- MAC ---

Method A: If `command -v brew` returns a path → run:
    brew install node

Method B: Install via nvm (no sudo needed). Run each command in order, stop if any fails:
    1. curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
    2. export NVM_DIR="$HOME/.nvm" && [ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
    3. nvm install --lts
    4. nvm use --lts

Method C (last resort, only if A and B both failed):
    1. curl -L -o ~/Downloads/node-installer.pkg https://nodejs.org/dist/v20.18.0/node-v20.18.0.pkg
    2. Tell me: "I downloaded the Node.js installer to your Downloads folder. Please double-click 'node-installer.pkg' and click Continue → Install (you'll be asked for your Mac password). Type 'done' when finished."
    3. Wait for 'done'.

--- WINDOWS ---

Method A: Check `winget --version`. If you get a version → run:
    winget install OpenJS.NodeJS.LTS --silent --accept-source-agreements --accept-package-agreements

Method B: If winget missing, download MSI silently:
    1. Invoke-WebRequest -Uri "https://nodejs.org/dist/v20.18.0/node-v20.18.0-x64.msi" -OutFile "$env:TEMP\node.msi"
    2. Start-Process msiexec.exe -ArgumentList "/i","$env:TEMP\node.msi","/quiet","/norestart" -Wait
       (If this fails with permission error, try without /quiet so the GUI installer appears: Start-Process "$env:TEMP\node.msi" -Wait)

Method C (last resort): tell me to open https://nodejs.org, click the green LTS button, run the installer with all defaults, type 'done' when finished.

AFTER any install method succeeds, tell me:
"Node.js installed. Please CLOSE and REOPEN this IDE so the new PATH is picked up. Then come back to this chat and type 'restarted'."

When I type 'restarted', verify: node --version
- If v18+ → say "✓ Node ready" and go to Step 2.
- If still missing → try the next method in the sequence. If all exhausted → tell me Method C (manual installer download).
