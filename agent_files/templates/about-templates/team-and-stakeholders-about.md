# Team and Stakeholders — Folder Contract

THE ONLY PLACE in `core_knowledge/` where people's names appear. All other knowledge files reference roles (e.g. "the platform team lead") and link here.

## Required files

- `contacts.md` — names, contact channels, time zones
- `team-structure.md` — teams, reporting lines, areas of responsibility
- `ownership-map.md` — who owns which component / process / system

## What does NOT go here

- Personal notes or private context → `private_knowledge/`
- Technical decisions → relevant component file or `architecture.md`

## Hard rules

- Names live ONLY in this folder. If you need to refer to a person elsewhere in `core_knowledge/`, use a role and link here.
- Never link to anything inside `private_knowledge/`.
