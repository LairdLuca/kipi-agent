HOW TO INSTALL KIPI
===================
 
Prerequisites: BMad must already be installed in your target project.
 
1. Open your target project in Cursor (the one with BMad installed)
2. Open a new chat with bmad-help
3. Paste the prompt below:
 
--- COPY EVERYTHING BELOW THIS LINE ---
 
I want to install the Kipi module (Core-Knowledge Keeper). I have cloned the kipi repo to my local machine but I haven't copied anything yet.
 
Please help me install it:
1. Ask me for the path where I cloned the kipi repo
2. Copy agent_files/ from that path into _bmad/kipi/ in this project
3. Copy all folders from cursor-skills/ into .cursor/skills/ in this project
4. Merge the cursorrules-template file into my existing .cursorrules (don't overwrite — merge intelligently)
5. Register Kipi in _bmad/config.yaml
 
--- END ---
