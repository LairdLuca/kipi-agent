# Start here

## Workshop participants

1. Read [workshop/1-READ-ME-FIRST.txt](workshop/1-READ-ME-FIRST.txt)
2. Copy all of [workshop/2-INSTALL-PROMPT.txt](workshop/2-INSTALL-PROMPT.txt) into a new IDE chat in your project
3. After install, use [workshop/3-AGENT-BUILDER-PROMPT.txt](workshop/3-AGENT-BUILDER-PROMPT.txt) for the custom-agent exercise

No advance setup required — the install prompt walks you through Node.js, BMad, and Kipi.

## Manual install (developers)

Prerequisites: BMad installed in your target project.

1. Copy everything under `agent_files/` into `_bmad/kipi/` in your project
2. Open a new chat and run `/kipi` — Kipi auto-installs IDE stubs and rules from `ide_adapters/` (or pick **[IN]** from the menu to re-run)

See [README.md](README.md) for full usage and knowledge layout.
